This is the real WP Updater page, running in your browser with fake servers and fake sites: nothing here touches a real site. Click Update all, open a site to see what changed, or exclude the staging copy in Settings.

Everything it does

Built for people who look after many WordPress sites for their clients, on shared hosting or their own servers.

Updates

WordPress, plugins, themes and translations
On every site with something pending, one after another, with one Update all. Or one site at a time.
Many servers at once
Add every server where you have SSH access. On each one it finds the WordPress sites in the account by itself.
What each site is running
Its WordPress version, what's pending with the current and new version, and what was updated afterwards.
What the server can't apply
When a new version needs a newer WordPress or PHP than the site has, like "Needs PHP 8.3", it shows under Can't update here and the tool skips it.
Keeps going if you close the page
Open it again to see the progress, the time left and the live log.

Safety

A verified database backup before each site
If the backup fails or comes out incomplete, that site isn't updated.
Duplicates are never updated
Two installs that share a database or an address, like a forgotten staging copy, are flagged and left alone until you exclude one.
A check that the site still loads
After each site, it opens its address and expects a working page. If it doesn't get one, the site is marked Check, with the reason.
Exclusions
Plugins, themes or whole sites that should never be updated.
Never as root
Files written by root break WordPress, so Test connection refuses a root account.

Backups

Full backups on your computer
The database and all the files of the sites you pick, whenever you want, leaving out the UpdraftPlus and WPvivid backup folders. You see how much room they take before you copy them.
A failed backup never replaces a good one
A full backup replaces the previous one only once it's complete. If it fails, the previous one stays.
Restoring
The README has the commands to put back a site's database, a single plugin, or a whole site from its full backup.

Try it on your computer first

The tool comes with a demo server of its own, with outdated sites to update. You need Docker Desktop and git. Then open localhost:8787 and add a server with host demo, port 22 and user demo, as the README shows.

git clone https://github.com/nicob201/wp-updater-free.git
cd wp-updater-free
docker compose --profile demo up -d
Get started

How it works

  1. Install it

    You need Docker Desktop and git. Run this, then open localhost:8787. It starts again by itself whenever Docker starts.

    git clone https://github.com/nicob201/wp-updater-free.git
cd wp-updater-free
docker compose up -d

  2. Add your server

    Copy the tool's SSH key into your hosting panel, then add the server's host, port and user and click Test connection. For Hostinger, cPanel and SiteGround, the form shows where each value is.

  3. Update all

    Check for updates shows what's pending on every site. Update all backs up each database and updates the sites, one after another.

Questions

Is it really free?

Yes. It's open source under the MIT license, with no paid plan and no account.

What does it install on my sites?

Nothing. It logs in over SSH with its own key and uses WP-CLI, which most hosts already have.

Which hosts does it work with?

Any host that gives you SSH access with a key, bash, WP-CLI and mysqldump or mariadb-dump. Most shared hosts have them, and on a VPS you can install them. Full backups also need rsync. Test connection checks all of it and tells you what's missing.

So far, listing sites has been tried on Hostinger, and updates on the tool's demo server. cPanel, SiteGround and VPS aren't tested yet: if you try it on one, open an issue to share how it went.

What if an update breaks a site?

Before each site, the tool saves its database and checks the copy is complete. After each site, it loads the address, and a site that doesn't answer with a working page is marked Check. The README has the commands to put back the database or a single plugin and, if you made a full backup with Back up sites…, the whole site. As with any update, try it on a staging site first.

Does it work on Windows and Mac?

Yes, with Docker Desktop. It's been tried on macOS and Windows 11. On Linux, Docker Engine with the Compose plugin works too.

Why not ManageWP or MainWP?

They're good tools, and they do more than this one, like uptime monitoring and client reports. Both need a plugin on every site you manage: ManageWP runs in its own cloud, with access to all your sites, and MainWP runs as a plugin on a WordPress site of its own, the dashboard. WP Updater installs nothing on your sites and runs only on your computer, with no account and nothing to pay. If you need monitoring and reports, use one of them. If you want updates with a backup first and nothing added to your sites, try this one.
