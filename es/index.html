Todos tus sitios WordPress, actualizados desde una página

Una herramienta gratuita que corre en tu computadora. Se conecta a tus servidores por SSH, hace una copia de la base de datos de cada sitio y actualiza WordPress, plugins, temas y traducciones en todos.

Es la página real de WP Updater, en inglés como la herramienta. Corre en tu navegador con servidores y sitios ficticios: nada de esto toca un sitio real. Haz clic en Update all, abre un sitio para ver qué cambió o excluye el sitio de staging duplicado en Settings.

Todo lo que hace

Pensada para quienes mantienen muchos sitios WordPress de sus clientes, en hostings compartidos o en sus propios servidores.

Actualizaciones

WordPress, plugins, temas y traducciones
En cada sitio con algo pendiente, uno detrás de otro, con un solo Update all. O un sitio a la vez.
Muchos servidores a la vez
Agrega cada servidor donde tengas acceso por SSH. En cada uno encuentra por sí sola los sitios WordPress de la cuenta.
Qué tiene cada sitio
Su versión de WordPress, qué tiene pendiente con la versión actual y la nueva, y qué se actualizó después.
Lo que el servidor no puede aplicar
Cuando una versión nueva necesita un WordPress o un PHP más nuevo que el del sitio, como "Needs PHP 8.3", aparece en Can't update here y la herramienta la saltea.
Sigue aunque cierres la página
Vuelve a abrirla para ver el progreso, el tiempo que falta y el registro en vivo.

Seguridad

Una copia verificada de la base de datos antes de cada sitio
Si la copia falla o sale incompleta, ese sitio no se actualiza.
Los duplicados nunca se actualizan
Dos instalaciones que comparten base de datos o dirección, como un sitio de staging olvidado, quedan marcadas y no se tocan hasta que excluyas una.
Un control de que el sitio sigue funcionando
Después de cada sitio, abre su dirección y espera una página que funcione. Si no la obtiene, el sitio queda marcado Check, con el motivo.
Exclusiones
Plugins, temas o sitios enteros que nunca deben actualizarse.
Nunca como root
Los archivos que escribe root rompen WordPress, así que Test connection rechaza una cuenta root.

Copias

Copias completas en tu computadora
La base de datos y todos los archivos de los sitios que elijas, cuando quieras, sin las carpetas de copias de UpdraftPlus y WPvivid. Ves cuánto lugar ocupan antes de copiarlos.
Una copia fallida nunca reemplaza a una buena
Una copia completa reemplaza a la anterior solo cuando está terminada. Si falla, la anterior se queda.
Restaurar
El README tiene los comandos para volver a poner la base de datos de un sitio, un solo plugin o un sitio entero desde su copia completa.

Pruébala primero en tu computadora

La herramienta trae un servidor de demo propio, con sitios desactualizados para actualizar. Necesitas Docker Desktop y git. Después abre localhost:8787 y agrega un servidor con host demo, puerto 22 y usuario demo, como muestra el README.

git clone https://github.com/nicob201/wp-updater-free.git
cd wp-updater-free
docker compose --profile demo up -d
Empezar

Cómo funciona

  1. Instálala

    Necesitas Docker Desktop y git. Corre esto y después abre localhost:8787. Vuelve a arrancar sola cada vez que arranca Docker.

    git clone https://github.com/nicob201/wp-updater-free.git
cd wp-updater-free
docker compose up -d

  2. Agrega tu servidor

    Pega la clave SSH de la herramienta en el panel de tu hosting, después agrega el host, el puerto y el usuario del servidor y haz clic en Test connection. Para Hostinger, cPanel y SiteGround, el formulario muestra dónde está cada dato.

  3. Update all

    Check for updates muestra qué hay pendiente en cada sitio. Update all hace una copia de cada base de datos y actualiza los sitios, uno detrás de otro.

Preguntas

¿Es gratis de verdad?

Sí. Es de código abierto con licencia MIT, sin plan de pago y sin cuenta.

¿Qué instala en mis sitios?

Nada. Entra por SSH con su propia clave y usa WP-CLI, que la mayoría de los hostings ya tiene.

¿Con qué hostings funciona?

Con cualquier hosting que te dé acceso SSH con clave, bash, WP-CLI y mysqldump o mariadb-dump. La mayoría de los hostings compartidos los tiene, y en un VPS los puedes instalar. Las copias completas además necesitan rsync. Test connection revisa todo y te dice qué falta.

Por ahora, el listado de sitios se probó en Hostinger, y las actualizaciones en el servidor de demo de la herramienta. cPanel, SiteGround y VPS todavía no se probaron: si la pruebas en alguno, abre un issue para contar cómo te fue.

¿Y si una actualización rompe un sitio?

Antes de cada sitio, la herramienta guarda su base de datos y revisa que la copia esté completa. Después de cada sitio, carga su dirección, y un sitio que no responda con una página que funcione queda marcado Check. El README tiene los comandos para volver a poner la base de datos o un solo plugin y, si hiciste una copia completa con Back up sites…, el sitio entero. Como con cualquier actualización, pruébala primero en un sitio de staging.

¿Funciona en Windows y Mac?

Sí, con Docker Desktop. Se probó en macOS y en Windows 11. En Linux también funciona Docker Engine con el plugin de Compose.

¿Por qué no ManageWP o MainWP?

Son buenas herramientas y hacen más que esta, como monitorear que los sitios estén en línea y armar reportes para clientes. Las dos necesitan un plugin en cada sitio que administras: ManageWP corre en su propia nube, con acceso a todos tus sitios, y MainWP funciona como plugin en un WordPress propio, que hace de panel. WP Updater no instala nada en tus sitios y corre solo en tu computadora, sin cuenta y sin pagar nada. Si necesitas monitoreo y reportes, usa una de ellas. Si quieres actualizar con una copia antes y sin agregar nada a tus sitios, prueba esta.
